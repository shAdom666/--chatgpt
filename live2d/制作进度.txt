复现
python tools/prepare_live2d_layers.py
node live2d/tools/build-project.mjs
注意：以上两步用于从源图重建，会覆盖自动生成工程；不会保留编辑器内手工图集改动。
已有工程只重建 PSD：node live2d/tools/build-project.mjs --psd-only。
闭嘴关键形补正：python live2d/tools/refine-mouth.py，保留现有图集，结果仍需在官方 Cubism 中打开并导出。
官方导出选择 SDK 3.0/Cubism3.0(3.2)、纹理 1/1（4096 px），并导出物理设置。
膝盖工程生成：python live2d/tools/add-knee-rig.py，以已有 fullbody 工程为输入，输出 natural 工程。
默认最终导出名为 GPTDragon.natural.moc3；之后执行：
node live2d/tools/finalize-model.mjs
node live2d/tools/validate-model.mjs
node tests/live2d-walk.cjs
node tests/natural-motion.cjs
powershell -NoProfile -File live2d/tools/check-runtime.ps1 -Mode showcase
node tests/natural-showcase.cjs
powershell -NoProfile -File build-live2d.ps1
powershell -NoProfile -File build.ps1
运行 Electron 时需清除 ELECTRON_RUN_AS_NODE；正式 GPTPet.exe 与启动脚本已处理。
--model-check 验证模型加载与真实顶点、像素；--animation-check 依次验证五种动作并生成 preview PNG。
--showcase-check 验证 12 种动作并录制 natural-actions.webm。编辑器可通过 tools/start-cubism.ps1 使用 2 GB Java 堆启动，避免默认按整机内存分配堆而导致导出失败。
--diagnostics 写本地诊断数据；没有开启 Node 调试端口。
