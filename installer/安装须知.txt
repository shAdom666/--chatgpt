龙娘桌宠 Live2D

本安装包包含当前白紫色龙娘模型、全身动作和 GPT 连接组件，以及 Electron 和 Live2D 运行环境。
支持 Windows 10（2004 或更新版本）、Windows 11 的 64 位环境，需要 .NET Framework 4.8 或更新版本。
使用桌宠不需要安装 Cubism 编辑器或 Node.js。

安装位置默认在当前用户的 LocalAppData\Programs\GPTDragonPet，不需要管理员权限。
可以创建桌面快捷方式；安装后从角色右键菜单选择动作、设置自由走动和打开聊天。
安装不会设置开机自启。

GPT 聊天需要自行在“连接设置”中填写 OpenAI API Key。API 用量按你的 API 账户计费。
安装包不包含任何人的密钥或聊天记录。已有本机连接设置会继续使用，卸载保留连接设置。

形象依据用户提供的参考图制作，原有美术素材的署名约定见 assets\NOTICE.md。
本项目是个人同人桌宠，与 OpenAI 无官方关联。第三方组件版权与许可保存在 licenses 及运行环境目录中。
