# 龙娘桌宠 v1.05

延续原来的白紫色 Q 版龙娘画风，增加侧身行走、转向、下蹲、侧躺蜷睡与起身。

## 下载和运行

下载下方 `GPTDragonPet-1.05-portable-x64.zip`，完整解压后双击 `GPTPet.exe`。运行包自带 Electron、Live2D 运行库及模型，不需要安装 Cubism 或 Node.js。支持 Windows 10 2004+/Windows 11 x64 兼容系统，需要 .NET Framework 4.8+。

右键角色或托盘，选择“蹲下”“侧躺蜷睡”“起身”。下蹲或睡觉时选择招手等动作，会先完成起身。

`GPTDragonPet-1.05-source.zip` 包含源码、生成素材和实际可编辑 CMO3 工程，适合继续修改。仓库中的 CMO3 通过 Git LFS 保存；克隆后请运行 `git lfs pull`。附件提供 SHA-256 校验文件和两段实际运行预览。

## 更新内容

- 左右侧身分别绘制并导出原生 Cubism 模型，腿部区分支撑与摆动，手臂、尾巴跟随运动。
- 按实际移动距离控制步频；启动先朝向移动方向，触边先减速，再经过四分之三视角和正面完成转向。
- 新增半蹲、下蹲、侧坐、侧撑及侧躺蜷睡姿势，睡眠带轻微呼吸起伏，逆序完成起身。
- 修正脚底定位、减速时步态不同步、拖动后残留步行状态及卧姿上方空白区域阻挡鼠标。
- 保留原有 GPT 聊天、托盘菜单、大小调整、置顶和贴边功能。

## 验证和当前范围

移动、步态与姿势检查覆盖 30–240 Hz；真实 Cubism 模型渲染、五姿势切换、呼吸形变、实际程序动作队列、运行包文件校验及解压后的桌面放置检查通过。测试没有调用付费 API。

左右行走使用原生网格与变形器；四分之三转向视角使用透明图片。卧姿过渡使用关键姿势混合与局部呼吸形变，尚未逐关节绑定全部卧姿部件；侧身脸部暂未独立绑定眨眼和嘴型。
