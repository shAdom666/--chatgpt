# 龙娘桌宠 v1.1

保持原来的白紫色 Q 版龙娘画风，修正正面对齐、改善手臂动作，并重做起卧过渡以消除全身重影。

## 下载与运行

下载 `GPTDragonPet-1.1-portable-x64.zip`，退出旧桌宠，完整解压后双击 `GPTPet.exe`。运行包自带 Electron、Live2D 运行库及模型，不需要安装 Cubism 或 Node.js。支持 Windows 10 2004+/Windows 11 x64 兼容系统，需要 .NET Framework 4.8+。本机 GPT 连接设置会保留。

`GPTDragonPet-1.1-source.zip` 包含源码、原始补绘素材和完整可编辑 CMO3 工程。仓库中的 CMO3 使用 Git LFS；克隆后请运行 `git lfs pull`。附件另含 SHA-256 校验文件、正面动作和起卧循环的实际运行视频。

## 修复内容

- 正面模型重新绑定颈部与躯干，固定衣领、腰线接触点，减小衣裙物理拉扯；清理残留图像并增加独立裙内衬。
- 双臂新增独立手腕和更密的肘部形变，招手具有准备、抬臂、肘腕错峰摆动与回落；消除物理和动作重复控制肘部的问题。
- 起卧增加手掌撑地与肘部支撑，共七个关键姿态，使用原生形变连接，切换时只显示一个角色，消除全身透明度混合产生的重影。
- 隐藏模型持续按受限时间步更新，避免恢复站姿时物理跳动；站姿准备动作保持脚底定位，其他动作等待起身完成后执行。
- 保留左右侧身走路、转向、GPT 聊天及原有桌面功能。修复模型由官方 Cubism Editor 5.3.04 保存并导出。

## 验证与当前范围

1260 帧起卧循环未发现双角色重叠或无效顶点，准备动作脚底位移为 0；12 种正面动作录制、30–240 Hz 动作检查，以及便携包解压后的文件校验、动作队列和桌面定位检查通过。验证未调用付费 API。

起卧仍采用关键姿态与局部原生形变，交接处会有少量服装细节切换，尚未逐关节绑定全部卧姿部件；侧身脸部暂未独立绑定眨眼和嘴型。
