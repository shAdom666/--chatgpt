# 龙娘桌宠 v2.0

白紫色龙娘正式采用 3D 模型。侧身走路时能看到裙侧开口和步幅。招手时前臂带动手腕转向屏幕，侧身时会抬起靠近屏幕的手。侧躺时裙边沿小腿垂落，在脚踝后侧收拢，两只鞋尖从裙边露出。

**Windows 用户请下载 `GPTDragonPet-2.0-portable-x64.zip`**，退出旧桌宠，完整解压后运行 `GPTPet.exe`。支持 Windows 10 2004+ 或 Windows 11 x64，需 .NET Framework 4.8 或更新版本。运行包自带 Electron、Three.js 和角色模型。

`GPTDragonPet-2.0-source.zip` 包含代码、原画、可编辑的 `dragon3d/Dragon.blend` 和完整 Live2D 工程。两个 ZIP 均附 SHA-256 校验文件。动作实录展示了正面与左右侧身招手、行走和起卧。

本版在起卧轨迹的 577 个采样姿态中均未检测到裙摆与双腿或鞋面相交，并通过了起卧中途反向和便携包启动检查。角色素材署名及非商业使用要求见 `assets/NOTICE.md`。
