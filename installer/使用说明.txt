龙娘桌宠 Live2D 1.05

启动：便携版请完整解压后双击 GPTPet.exe。安装版也可从桌面或开始菜单启动。
运行包自带模型和运行环境，不需要 Cubism、Node.js 或另装 Electron。

单击角色：打开 GPT 聊天。
按住拖动：移动桌宠；默认松手后平滑落到屏幕底边。
右键角色：选择招手、开心、轻轻跳一下、蹲下、侧躺蜷睡和起身。睡觉或蹲下时选择其他动作，会先起身。
“日常动作”：伸懒腰、左右张望、点点头、摊手歪头、整理裙摆。
“日常小动作”：控制空闲时随机做动作。
“自由走动”：控制沿屏幕底边漫步。
关闭“贴住屏幕底边”后可以自由摆放。
“回到右下角”可以找回角色；支持 240、320、400 三种窗口宽度。
托盘图标右键也能打开菜单，双击可聊天。选“退出”关闭桌宠。

连接 GPT：聊天窗口中点击“连接设置”，填写自己的 OpenAI API Key 和可用模型名称。
保存设置不会调用 API，发送消息时才连接。Enter 发送，Shift+Enter 换行。
密钥使用 Windows DPAPI 加密，保存在 %LOCALAPPDATA%\GPTDesktopPet\settings.json。
安装包不附带密钥；更新安装与卸载保留上述本机设置。
聊天内容只在本次窗口内存中保存。API 用量由你自己的 API 账户计费。

移除：便携版退出后删除解压文件夹即可。此前的安装版可从 Windows 设置或开始菜单卸载。
本程序不会设置开机自启。素材署名见 assets\NOTICE.md，组件许可见 licenses 和 Electron 目录。
